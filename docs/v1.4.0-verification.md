# v1.4.0 verification

- Built from v1.3.1; versionCode 18, versionName 1.4.0.
- Debug APK build, Android unit tests, recipe-core tests, backend tests and Android lint passed.
- Six focused instrumentation tests passed on the Android API 37 emulator: photo preparation and
  analysis/review, retry after network failure and empty results, cancellation with late callback,
  editable review restoration after recreation, atomic pantry merging and duplicate handling,
  image size/orientation and metadata removal, content-URI access, English/Arabic layouts,
  and the existing cooking timer regression test.
- The photo flow uses deterministic responses only in the instrumentation APK. No live Gemini
  image recognition request was made during verification. Actual camera-app capture and external
  picker interaction still need a hands-on check; image loading uses real JPEGs in the tests.
- English and Arabic home/review views were rendered for visual inspection. Local images and
  test logs are under ignored `work/v1.4.0/`.
- Public APK contains no private Gemini bootstrap asset. Photos, phone data backups, signing keys
  and credentials are excluded from Git.

## Signing and phone migration

- Installed and launched v1.4.0 (versionCode 18) on the connected RMX3840 phone after owner-approved
  reinstall. The previous installation reported v1.3.0 (versionCode 16). Restored the app files and
  preferences from a local backup; the SHA-256 of `dishroulette_ui.xml` matched before and after.
  Gemini must be reconnected because the previous Keystore key was removed during uninstall.

This release is built with this workstation's debug signing key. Older APKs signed on a different
computer cannot be updated in place with it. Keep using the same signing key for future builds.
Do not uninstall an existing installation without backing up its data and obtaining the owner's
approval. Android removes its Keystore encryption keys on uninstall, so restoring encrypted
Gemini credential bytes alone does not restore the connection; reconnect Gemini in Settings.
